# MERN Full Stack Internship

This repository contains the tasks I am completing during my MERN Full Stack Internship at Alaukik iTech Solution. I am learning new concepts and practising them by creating small projects.

## Folder Details

- **Frontend:** All my HTML, CSS and JavaScript files.
- **Backend:** My Node.js and Express.js work.

## Daily Tasks

### Day 1 – Login Page
I created a login page using HTML and CSS and worked on its design.

### Day 2 – Registration Page
I created a registration form with fields like name, date of birth, gender, email and password.

### Day 3 – Login and Registration
I used JavaScript to switch between the login and registration forms without reloading the page.

### Day 4 – Form Validation
I added validation to check the email, password length and whether both passwords match.

### Day 5 – Dashboard
I created a dashboard with a sidebar, navigation links and statistics cards.

### Day 7 – Task Creation Modal
I created a popup form to add a task with a title and description. I also added Save and Delete buttons.

### Day 8 – Dynamic Task Management
I used JavaScript to add and delete tasks dynamically and manage their status.

### Day 9 – Local Storage
I used localStorage to save tasks so that they stay there even after refreshing the page.

### Day 11 – Node.js and Express Setup
I created a basic server using Node.js and Express.js and tested it on port 5000.

### Day 12 – Express Routing
I created GET routes to show a welcome message and a list of tasks. I also created a POST route to add new tasks and used middleware to check request details in the terminal. I tested these routes using PowerShell.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run the Backend

1. Open the Backend folder in the terminal.
2. Run `npm install`.
3. Run `node server.js`.
4. Open `http://localhost:5000` to see the welcome message.
5. Open `http://localhost:5000/tasks` to see the task list.
